# venue_autocalib spec (calib tasarım workflow, 9 ajan)

**Modül:** pitch/venue_autocalib.py (new orchestrator; CPU-only, no learned net). Public entry: autocalibrate_venue(...). It is a PROPOSER+GATE that wires together the existing auto_calib / line_calib / homography / template / height_scale / scale_snap / venue_registry / calibrate_field building blocks and adds only the four documented-missing pieces (undistort-before-chamfer, optimize_LW grid, L/R+180 disambiguation, goal-side gate).

## Genel
One headless module that, given a fixed night-camera clip + RF-DETR player boxes + a venue record, returns a QA-passed PitchHomography (aspect-correct H_img2pitch, undistorted-px->metre) with absolute scale supplied by the height ruler, or None (honest refuse -> manual fallback). It fuses the three designs: from Design 3 the resolution-normalized, fail-closed spine and per-venue k1; from Design 2 the undistort-FIRST multi-start chamfer with an (L,W)-topology grid scored by center-circle/penalty-box IoU; from Design 1 the key insight that aspect is pinned WITHOUT the far corners (two vanishing points from the bright near/mid touchlines + center-line/center-circle), so the dark far third is marked no-coverage instead of fabricated. The hard problem is reduced to recovering a correct-aspect ground homography; scale_anchor stays None through calibration and is filled afterward by pitch/height_scale.make_v_height (~1.75 m universal ruler). Every output passes a 4-layer un-gameable gate before any canonical JSON is written, and routes through venue_registry.attach_calibration as the authoritative reject filter. Nothing is hardcoded to Cankaya: dims/template come from venue_registry, k1 is per-camera, cx,cy=W/2,H/2 from the actual clip resolution.

## Adımlar
### 0. Enumerate + template + resolution-normalize
- **yöntem:** venue_registry.build_from_scan -> rank(measurable_only=True) -> resolve_camera(cam); CameraRecord.to_template()/resolve_dims() picks five_a_side vs seven_a_side + provisional (L,W). Read clip (W_img,H_img) once; set cx=W_img/2, cy=H_img/2 and a scalar s=diag(W_img,H_img)/diag(1920,1080); thread cx,cy,s into EVERY natural-camera/pixel-threshold call (kills the hardcoded 960/540 and fixed-px 720p hazard).
- **çıktı:** PitchTemplate (provisional L,W), cx, cy, s
- **reuse:** venue_registry.build_from_scan, rank, resolve_camera, CameraRecord.to_template/resolve_dims; PitchTemplate.five_a_side/seven_a_side
### 1. Static line map (occluder-robust, adaptive)
- **yöntem:** build_static_line_map(video, n_frames=400, player_boxes_per_frame=RF-DETR xyxy, percentile auto-bumped 50->60-70 if line-pixel fraction is low). Temporal median washes out moving players/shadows; _inpaint_boxes de-biases goalmouth loiter. Make white_line_mask's high-L cut adaptive (upper-percentile of L instead of fixed 0.55) so a dark far third still yields pixels. select_calib_frame picks a low-occupancy frame for the human overlay snapshot.
- **çıktı:** L_raw (HxW float32 [0,1]) + overlay frame
- **reuse:** auto_calib.build_static_line_map, white_line_mask, _inpaint_boxes, select_calib_frame
### 2. Per-venue fisheye k1 (fills 'no distortion estimate' gap)
- **yöntem:** detect_lines(L_raw) HoughLinesP -> take longest physically-straight touch/goal ridges as bowed polylines; 1-D sweep of single radial k1 (principal point=centre, f0=max(W,H)), choosing k1* that minimizes fit_line_tls(...).rms of the undistorted ridge edge pixels (equivalently PitchHomography.estimate_distortion_from_lines). Build K, dist=[k1*,0,0,0,0]; set_distortion; flag distortion_confidence='low'. If straightness never converges below threshold -> flag strong_fisheye and lower venue confidence.
- **çıktı:** (K, dist), distortion_confidence flag
- **reuse:** auto_calib.detect_lines; line_calib.fit_line_tls; PitchHomography.estimate_distortion_from_lines, set_distortion
### 3. Undistort-BEFORE-chamfer (the load-bearing fix)
- **yöntem:** cv2.initUndistortRectifyMap + remap L_raw -> L_und with (K,dist). ALL subsequent geometry runs in undistorted pixel space, so the planar homography fits straight lines and aspect is correct (auto_calib's documented gap closed).
- **çıktı:** L_und (HxW float32 [0,1])
- **reuse:** cv2.initUndistortRectifyMap/remap; PitchHomography.undistort_points (for any raw points)
### 4. Coarse chamfer + (L,W) topology grid (implements optimize_LW)
- **yöntem:** VP-init: cluster Hough segments into two orientation pencils -> vanishing_point per pencil -> coarse 2-VP rectifying H as a strong seed; ADD auto_calib._init_corner_hypotheses (bbox-trapezoid + 8 L/R+180 symmetry starts) as fallback. Build a 2-level pyramid (x0.5,x1). Outer loop over a SMALL halisaha grid (7v7 L 36..44/W 22..28 step 2; 5v5 L 25..30/W 15..20): for each (L,W) run register_template_chamfer(L_und, template, multi_start=True). Score each (L,W,H) by chamfer PLUS center-circle ellipse / penalty-box reprojection IoU (the otherwise-unused topology) so the global-rescale degeneracy is broken and the aspect is picked. Keep best (L,W,H).
- **çıktı:** chosen (L,W), coarse H_img2pitch, surviving symmetry hypotheses
- **reuse:** auto_calib._init_corner_hypotheses, register_template_chamfer, _dt_from_mask, _chamfer_cost, _line_iou, detect_lines (ellipse); line_calib.vanishing_point; scale_snap.snap_size; PitchTemplate.line_points_m/line_segments_m
### 5. Resolve L/R + 180 (fills symmetry + goal-side TODOs)
- **yöntem:** Among symmetry survivors apply asymmetric cues (NEVER the symmetric chamfer): (a) camera-behind-goal prior — image-wide endline is NEAR (X=0), touchlines converge upward; (b) detect lower-centre goalposts -> pick_lines.goalpost_point_lms world (0, W/2 -+1.5) as point_lms; (c) goal-side reprojection check: reprojected goal-lines MUST land x~0 / x~L, never on a touchline; (d) height_scale.decompose_ground_homography(H,cx,cy) pose sanity: camera centre behind a goal-line, C_y~W/2, height 2-8 m, axis along length. If two survivors stay equally plausible -> REFUSE (return None) rather than guess; orientation_hint overrides as a one-time seed.
- **çıktı:** single oriented H, or None (refuse)
- **reuse:** pick_lines.goalpost_point_lms; height_scale.decompose_ground_homography, estimate_focal; PitchTemplate.goal_centers_m
### 6. Relabel -> line re-fit WITH real QA (closes the silent-QA gap)
- **yöntem:** Use oriented H to LABEL detected segments into the 5 named keys (touchline_y0/yW, endline_x0/xL, halfway); sample >=2 ridge-snapped points per line (_snap_to_ridge on L_und); feed line_calib.build_homography_from_lines(cam, template, line_clicks, K, dist, point_lms=goalposts, static_line_map=L_und). That routes through PitchHomography.calibrate_manual(already_undistorted=True) which POPULATES _img_pts_und/_world_pts so reproject_error_map() actually runs (set_homography alone leaves NaN QA). corners_from_lines recovers off-frame corners as legal world coords; <4 well-conditioned -> RuntimeError = honest refuse.
- **çıktı:** PitchHomography with populated correspondences + _qa, qa_line (metre QA)
- **reuse:** line_calib._snap_to_ridge, build_homography_from_lines, corners_from_lines, fit_line_tls, line_point_residual_qa; PitchHomography.calibrate_manual(already_undistorted=True), reproject_error_map
### 7. Strict multi-gate (all must pass, else status=rejected)
- **yöntem:** Accept ONLY if ALL pass, thresholds scaled by s: (a) auto_calib.self_verify_gate (line_iou>=0.30, chamfer<=6px*s, both_halves, spread) + the now-implemented goal-side check; (b) stats/topdown_stats.accept_calib_qa(homo._qa) (median_px<=15*s, n_landmarks>=6, near<=far*1.5 backwards-H test, no-NaN per_zone); (c) line_point_residual_qa metre-domain residual with BOTH touchlines near+far sane (catches near/far inversion the pixel gate misses); (d) pose sanity from step 5 (height 2-8 m). Any fail -> status='rejected', return None, log gate['reasons'] -> manual pick_lines fallback.
- **çıktı:** accept/reject decision + gate reasons log
- **reuse:** auto_calib.self_verify_gate; stats/topdown_stats.accept_calib_qa; line_calib.line_point_residual_qa; height_scale.decompose_ground_homography
### 8. Metric scale ladder (separate, aspect-only H in)
- **yöntem:** Keep scale_anchor=None through gating. Ladder, best-available+honest: (a) on-site tape -> scale_from_known_distance (verified exact); else DEFAULT (b) height_scale.make_v_height(calib, out, tracks) with venue cx,cy -> c=1.75/median_height, self-gates n>=200, CV<=0.20, camera-height 2-8 m, writes scale_anchor=null if it cannot honestly assert; else (c) scale_snap.make_v3 catalog snap (isotropic, QA-invariant). venue_registry.goal_width_crosscheck vs 3.0 m as an independent width anchor. If scale gates fail, calib stays relative_m (metres withheld, never fabricated).
- **çıktı:** scale_anchor (verified | approx-band | null)
- **reuse:** height_scale.make_v_height, player_height_scale, scale_from_known_distance; scale_snap.make_v3, snap_size, scale_state, should_force_reproject; venue_registry.goal_width_crosscheck
### 9. Persist + commit contract + coverage + drift
- **yöntem:** On full pass set homo.status='auto_accepted', homo.save('calib/<cam>.json'); route JSON through venue_registry.attach_calibration (authoritative reject filter) -> sync_calib_json + _recompute_metric_claim flips metric_claim_allowed ONLY when dims_confidence>=0.6 AND anchor passed. Write coverage sidecar via coverage_confidence_map (far-third no-coverage). Optionally render calibrate_field.run_calibration QA overlays (orange grid on RAW + top-down) via redistort. Periodically re-run PitchHomography.drift_check for tripod nudge -> status='recalibrate'.
- **çıktı:** calib/<cam>.json + coverage sidecar + QA PNGs, registry updated
- **reuse:** PitchHomography.save/load, qa_overlay, drift_check; line_calib.coverage_confidence_map, _redistort; calibrate_field.run_calibration, redistort; venue_registry.attach_calibration, sync_calib_json, _recompute_metric_claim

## Belirsizlik çözümü
Chamfer/IoU/center-circle are dihedral-symmetric so residual CANNOT pick the mirror/180-flip; four independent asymmetric disambiguators are combined and any tie is a refuse, not a guess: (1) camera-behind-goal geometric prior wired into init — the image-wide endline is NEAR (world X=0) and touchlines converge to a vanishing point ABOVE, fixing the length/depth axis and collapsing 4 rotations to a 2-fold; (2) goalpost detection in lower-centre -> pick_lines.goalpost_point_lms asymmetric point anchors at world (0, W/2 -+1.5) fed as point_lms to line_calib.build_homography_from_lines, breaking L/R; (3) the goal-side reprojection gate (the explicit self_verify_gate TODO, now implemented) requires reprojected goal-lines at x~0 and x~L and never on a touchline; (4) decisive pose sanity — height_scale.decompose_ground_homography keeps only the orientation whose physical camera centre sits behind a goal (C_x<0 or >L), C_y~W/2, height 2-8 m, optical axis along length; a mirror/180 lands the camera underground or off-axis. The center circle is deliberately NOT used for orientation (symmetric). If no asymmetric evidence exists (symmetric venue, no posts, pose tie) the pipeline returns None and requests orientation_hint or one on-site goalpost click.

## Ölçek
Decoupled from the homography — the key lever. Calibration only delivers a QA-passable aspect-correct H (scale_anchor=None / relative_m). Aspect RATIO L/W is recovered geometrically (two vanishing points + center-circle conic, or near-endline->center-line spacing vs touchline spacing) so far corners are never needed; the discrete (L,W) is snapped to the 5v5/7v7 catalog (scale_snap.snap_size) and validated by the small grid that minimizes line_point_residual_qa (this is the missing optimize_LW). Absolute metres come downstream via the ladder, default = pitch/height_scale.make_v_height: decompose H to camera pose, single-view metrology on clean upright RF-DETR detections, c = 1.75 m / median player height, self-gated on n>=200, CV<=0.20, camera-height 2-8 m, emitted approximate=True with a +-band. On-site tape (scale_from_known_distance) gives verified=True exact metres when available; venue_registry.goal_width_crosscheck vs 3.0 m is an independent cross-check; scale_snap.make_v3 catalog snap is the last resort. cx,cy=W_img/2,H_img/2 are threaded into estimate_focal/decompose/player_height_scale per resolution so 720p does not silently violate the natural-camera assumption. If scale gates fail, metres are withheld (relative_m), never fabricated; scale_snap.scale_state drives the downstream unit label.

## QA-gate
Fail-closed, multi-layer, un-gameable, ALL required, every failure logged for triage; pixel thresholds scaled by s=diag(W,H)/diag(1080p). PRECONDITION (closes the biggest honesty risk): the auto H is produced through line_calib.build_homography_from_lines -> PitchHomography.calibrate_manual(already_undistorted=True) so _img_pts_und/_world_pts/_qa are populated and reproject_error_map is NOT silently empty (set_homography alone leaves NaN QA -> would be auto-accepted with no real QA). GATE LAYERS: (1) auto_calib.self_verify_gate: line_iou>=0.30, chamfer<=6px*s, both_halves True, spread_ok, PLUS goal-side placement (goal-lines at x~0/x~L). (2) stats/topdown_stats.accept_calib_qa(homo._qa): median_px<=15*s, n_landmarks>=6, near<=far*1.5 (backwards-H/near-far-inversion test), no NaN per_zone. (3) line_calib.line_point_residual_qa: bounded per-line median_m/p95_m with BOTH touchlines near+far sane (metre-domain residual cannot be gamed by exact-fit corners; catches mislabels). (4) Pose sanity: height_scale.decompose_ground_homography camera-height 2-8 m + pose not flipped (catches wrong-aspect/global-rescale that pixel QA misses). (5) Conditioning: <4 well-conditioned finite corners (corners_from_lines sin_angle/extrap) -> RuntimeError honest refuse; that region marked no-coverage. Any failure -> status='rejected'/'recalibrate', NO canonical JSON, route to manual. Final pass re-applied by venue_registry.attach_calibration; metric_claim_allowed unlocks ONLY when dims_confidence>=0.6 AND scale anchor passed.

## Doğrulama planı (GT'siz)
No ground truth on downloaded venues, so validate by internal consistency + invariants (all already computable from existing functions): (1) SELF-REPROJECTION: hold out ~30% of ridge-snapped line samples, fit H on the rest, measure line_point_residual_qa median_m/p95_m on the held-out set; require held-out p95 within ~1.3x of train p95 (overfit detector). (2) CIRCLE-MAPS-TO-CIRCLE: warp the detected center-circle pixels through H into metre space, fit an ellipse; require eccentricity small and radius ~ template center_circle_r_m (4 m 7v7 / 3 m 5v5) within band — a wrong aspect makes the circle an ellipse. This is the single strongest aspect check and needs no labels. (3) RIGHT-ANGLE / PARALLELISM: reproject the four boundary lines to metres; touchlines must be parallel and perpendicular to endlines (corner angles ~90 deg within tol). (4) HEIGHT-CV SANITY: run height_scale.player_height_scale; require >=200 clean upright detections, CV<=0.20, and median height landing at 1.75 m only AFTER scaling — the CV itself is a geometry check (a skewed H inflates height CV). (5) CAMERA-HEIGHT PLAUSIBILITY: decompose_ground_homography must give 2-8 m and camera behind a goal. (6) GOAL-WIDTH CROSSCHECK: if goalposts detected, goal_width_crosscheck residual<5% vs 3.0 m — independent of the height scale. (7) MIRROR/FLIP NEGATIVE TEST: deliberately feed the mirrored symmetry hypothesis and confirm the gate REJECTS it (proves the disambiguator works). (8) DRIFT/STABILITY: split the clip into early/late halves, calibrate each, require H agreement (reprojected corner displacement < a few px*s) — fixed camera should be stable. (9) RESOLUTION ROBUSTNESS: downsample a 1080p venue to 720p, re-run with cx,cy=640,360, require the same accept decision and aspect within band (regression test for the 720p hazard). (10) COVERAGE HONESTY: coverage_confidence_map covered_frac reported WITH metre-QA, never as an absolute bound; confirm far-third flagged no-coverage on dark venues. Run all venues through and tabulate accept/reject + reasons; manually eyeball qa_overlay PNGs for the accepted ones (spot-check, not ground truth).

## Riskler
- **Night / faint low-contrast lines defeat fixed white_line_mask thresholds (L>0.55,S<0.45) -> sparse L_static, optimizer stalls in a local basin** → Adaptive high-L cut (upper-percentile of L per clip), percentile bump 50->60-70 in build_static_line_map, VP-init + 8-way multi-start + coarse-to-fine pyramid to widen the DT basin; a near-empty map ultimately reject-refuses rather than fits noise.
- **720p vs 1080p: hardcoded cx=960/cy=540 and fixed-px thresholds silently violate natural-camera assumption / spuriously reject** → Set cx,cy=W_img/2,H_img/2 from actual resolution and thread into estimate_focal/decompose/player_height_scale; scale every pixel threshold (chamfer, ransac, median, drift, line_iou dilation) by s=diag/diag(1080p). Explicit downsample regression test (validation step 9).
- **Fisheye residual beyond a single radial k1 (wide-angle dome) -> planar H absorbs barrel curvature and skews aspect** → Estimate k1 by line-straightening and UNDISTORT BEFORE chamfer (closes auto_calib's gap); residual bow then surfaces as elevated line_point_residual_qa p95 / low line_iou and is REJECTED. If straightness never converges, flag strong_fisheye -> manual/checkerboard. Single-k1 carried as distortion_confidence='low'.
- **L/R + 180-degree mirror ambiguity — chamfer residual is symmetric and cannot break it** → Four asymmetric disambiguators (camera-behind-goal prior, goalpost point_lms, goal-side reprojection gate, decompose pose sanity); a true tie REFUSES (None) and asks for orientation_hint/one click. Negative mirror test in validation proves the gate rejects the flip.
- **Faint/pixel-poor far third at night -> far corners under-constrained; far-end aspect could drift undetected** → Aspect is pinned WITHOUT far corners (two VPs from bright near/mid touchlines + center-line + center-circle conic); far corners synthesized as legal off-frame world coords with per-corner conditioning exposed; <4 well-conditioned -> refuse; far third explicitly marked no-coverage so metric stats are suppressed there, not extrapolated.
- **Occlusion / goalmouth loiter — a near-static player leaves a ghost ridge in the temporal median that inpaint misses** → RF-DETR box inpaint (_inpaint_boxes) before median + percentile maps + ~400-frame sampling; residual ghost raises chamfer and is usually rejected. A faint ghost mildly biasing the fit is caught by the metre-domain line residual gate.
- **Variable / non-standard pitch dimensions -> wrong L/W skews aspect even at low chamfer (global-rescale degeneracy invisible to chamfer+line_iou)** → Implement optimize_LW as a small (L,W) grid scored by chamfer PLUS center-circle/penalty-box reprojection IoU (the on-pitch absolute-size tiebreak); snap to catalog (snap_size) and validate by line residual. Truly non-standard venues snap to nearest with the error inside the +-band, and the goal_width_crosscheck + height-scale camera-height plausibility flag gross rescales. circle-maps-to-circle (validation step 2) is the un-gameable aspect check.
- **Silent-QA acceptance — set_homography leaves _img_pts_und/_world_pts None so reproject_error_map returns all-NaN and a bad calib is 'accepted' with no real QA** → NEVER use set_homography for the auto path; produce H via build_homography_from_lines -> calibrate_manual(already_undistorted=True) which populates correspondences and _qa, so accept_calib_qa runs for real. This is enforced as a precondition of the gate.
- **Side/elevated mount (not behind goal) breaks near/far depth ordering and the top=far depth-zone QA proxy -> flip can pass silently** → decompose_ground_homography pose check requires camera behind a goal-line; if it isn't, the venue is flagged and requires orientation_hint or one human click rather than auto-accept.
- **height_scale starvation (short/dark/occluded clip, <200 clean upright detections) -> metres unjustified** → make_v_height self-gates (n>=200, CV<=0.20, camera-height 2-8 m) and writes scale_anchor=null; output stays relative_m (aspect-correct, unitless) — not wrong, just not metric. scale_snap.scale_state labels the unit honestly downstream.
- **Tripod nudge mid-match -> single fixed H drifts, stats degrade** → Periodic PitchHomography.drift_check(line_map, max_resid_px*s) flips status to 'recalibrate'; early/late-half stability test in validation surfaces unstable mounts.
- **Provider/URL grammar or env classification mismatch in venue_registry -> camera skipped or wrong template/dims** → Fail honestly: a skipped camera gets no calib (no silent wrong geometry); template/dims default to standard with conf 0.25 which keeps the venue relative-only until a higher-confidence dims source or the height ruler unlocks metres. Validate that resolve_camera returns a record before running the pipeline.
